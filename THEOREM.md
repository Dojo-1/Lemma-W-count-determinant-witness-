# Flip-connectivity of octonion bracketing classes

Evidence labels: **P** proved (general argument), **P-fin** proved for every word of the stated lengths by an exact, sampling-free computation built only from the lemmas below, **H** open.

## Setting

A *word* `w = w₁…wₙ` over letters; a *bracketing* is a planar binary tree with leaves `1..n`. Each bracketing `T` induces a polynomial map `𝕆^L → 𝕆`. `T ~ T'` iff the maps agree. Bracketings form the vertices of the associahedron `Kₙ`; an edge (*flip*) replaces a subterm `(AB)C` by `A(BC)`, where `A, B, C` are bracketings of consecutive segments `a, b, c` of `w`. A class is *flip-connected* if it induces a connected subgraph of `Kₙ`.

**Theorem (P for all n).** In 𝕆 every class of `w` is flip-connected iff `w` has ≤ 2 distinct letters or every letter of `w` occurs in one contiguous run. The number of words of length `n` (up to renaming) with a disconnected class is `Bell(n) − 2ⁿ + n`.

## General lemmas (P)

**L1 (context cancellation).** `C[S₁] ~ C[S₂] ⇔ S₁ ~ S₂` for any context `C`.
*Proof.* `C[S]` is `S` composed with left/right multiplications by values of the other subterms of `C`. For generic letter values these are nonzero, and multiplication by a nonzero octonion is bijective (𝕆 is a division algebra). So equality on a dense set forces `S₁ = S₂` on a dense set, hence identically. ∎
*Consequence.* A flip is an edge inside a class iff its local associator `[A,B,C]` vanishes identically.

**W (count-determinant witness).** Let `N` be the 3 × |letters| matrix of letter multiplicities of `a, b, c`. If `rank N = 3` then `[A,B,C] ≢ 0` for all bracketings `A, B, C`.
*Proof.* Pick letters `x, y, z` with `det N_{xyz} ≠ 0`. Specialise `x, y, z ↦ exp(θe₁), exp(θe₂), exp(θe₄)` and all other letters `↦ 1`. Each segment equals `1 + θΣₛ + O(θ²)` with `Σₛ = Σ N_{s,ℓ} e_ℓ`. The associator vanishes when an argument is real, so `[A,B,C] = θ³[Σ_a, Σ_b, Σ_c] + O(θ⁴)`. By trilinearity and alternation this is `θ³ det(N_{xyz}) [e₁,e₂,e₄] + O(θ⁴)`, and `[e₁,e₂,e₄] ≠ 0` because `1, 2, 4` are independent in 𝔽₂³ (`e₄` lies outside the quaternion algebra spanned by `e₁, e₂`). ∎
*Corollary.* The in-class flip graph is a subgraph of `D_N` := {flips with `rank N ≤ 2`}. So **two equivalent bracketings in different `D_N`-components prove that their class is disconnected.**

**V (vanishing).** `[A,B,C] ≡ 0` if `abc` uses ≤ 2 letters, or two of `a, b, c` are powers of one letter `x`.
*Proof.* In the first case the values lie in an algebra generated by two letters; in the second, two values lie in `span{1, x}` (𝕆 is quadratic), and all three lie in the algebra generated by `x` and the third value. Artin's theorem makes either algebra associative. ∎

**I (interval rank lemma).** If `w` is an interval word, `a, b, c` are consecutive segments, `abc` has ≥ 3 letters, and no two of `a, b, c` are powers of one letter, then `rank N = 3`.
*Proof.* Order letters by block. Supports are letter-intervals with `max S_a ≤ min S_b`, `max S_b ≤ min S_c`.
- *Case |S_b| = 1*, `S_b = {p}`. Neither `a` nor `c` is a power of `p`, so `a` has a letter `x < p` and `c` has a letter `z > p`. On columns `(x, p, z)` the matrix is `[[aₓ, a_p, 0], [0, b_p, 0], [0, c_p, c_z]]`, with determinant `aₓ b_p c_z ≠ 0`.
- *Case |S_b| ≥ 2*, `p = min S_b < q = max S_b`; then `S_a ∩ S_c = ∅`. Either `S_a = {p}` or `a` has `x < p`; either `S_c = {q}` or `c` has `z > q`. Choose `y ∈ S_b` with `p < y < q` when it exists. In each of the four combinations the matrix on columns chosen from `{x or p} × {y or p or q} × {z or q}` is triangular with nonzero diagonal. If `S_a = {p}` and `S_c = {q}`, the ≥ 3-letter hypothesis forces such a `y` to exist. ∎
Exhaustive brute-force check: 1,997,801 segment triples of interval words up to length 12, 0 violations.
*Corollary.* For interval words the in-class flip graph **equals** `D_N` (W gives ⊆; I + V give ⊇). Classes are unions of `D_N`-components.

**Θ (θ³ invariant).** For integer vectors `v_ℓ ∈ ℤ³` let `I_v(T) = Σ_{i<j<k} det(v_{wᵢ}, v_{wⱼ}, v_{wₖ}) · s_T(i,j,k)`, with `s_T = +1` if `T` induces `((ij)k)` on `{i,j,k}` and `−1` if `(i(jk))`. If `I_v(T) ≠ I_v(T')` then `T ≁ T'`.
*Proof.* Specialise `ℓ ↦ exp(θ q_ℓ)` with `q_ℓ = v_ℓ¹e₁ + v_ℓ²e₂ + v_ℓ³e₄`. Up to `θ³`, two bracketings differ only through associators of three distinct positions. Repeated-letter triples cancel (flexible and alternative laws). Associators of three generic elements of the span of `e₁, e₂, e₄` equal `det · [e₁,e₂,e₄]`. So `value(T) − value(T') = ½(I_v(T) − I_v(T'))[e₁,e₂,e₄]θ³ + O(θ⁴)`. ∎

**K (killing).** Setting a letter to `1` sends bracketings of `w` to bracketings of the shorter word `w′`. It maps `D_N`-edges to `D_N`-edges or to identities (deleting columns cannot raise rank), and identities to identities. **Moufang moves lift.** In each pattern, `(ab)(ca)`, `((ab)a)c`, `((ca)b)a`, every gap between consecutive leaves borders a non-repeated variable (`b` or `c`), so killed letters can be absorbed there or into the context. Hence a Moufang move between different `D_N`-components of `w′` lifts to one in `w`. (Alternative-law moves need not lift: `(xx)y` from `x d x y`.)

**R (rigid separator).** Call an interval `J` (|J| ≥ 2) *absolutely rigid* if every triple (split of `J`, adjacent nonempty interval on either side) has `rank N = 3`.
- **Lemma.** If `J` is absolutely rigid, then "`J` is a node of `T`" is constant on `D_N`-components.
- **Proof.** A node with span `J` is created or removed only by a rotation at its parent in which `J` is the inner node. That rotation's segment triple is (split of `J`, sibling), and the sibling is an adjacent nonempty interval. By rigidity it has rank 3, so it is not a `D_N`-edge. ∎
- **Closed form (three letters).** Let `t = counts(J)`, and `n_s = u_s × t` for each split `s` (`u_s` = counts of the left part). `J` is rigid iff no nonempty prefix-count vector of the right context and no nonempty suffix-count vector of the left context is orthogonal to any `n_s`, i.e. two lattice walks avoid finitely many planes. For `J = pq`: rigid iff each side of `J` is the word boundary or the third letter.
- **Consequence.** A Moufang move `T0 → T1` together with a rigid `J ∈ nodes(T0) Δ nodes(T1)` is a *local, finitely checkable* certificate that `T0, T1` lie in different `D_N`-components: no component search is needed.

**R′ (stable-node separators, P).** Lemma R tests a node against every conceivable sibling. Along a `D_N`-path, however, the siblings are constrained by the nodes that cannot move. Fix a bracketing `T`.
- **Self-certifying sets.** A set `S` of internal nodes of `T` is *self-certifying* if every rotation that would delete some `J ∈ S` has count-matrix rank 3. Here "rotation" means: children `L, R` of `J` and a sibling `I`, with `L, R, I, J∪I` laminar with `S`, and the newly created node laminar with `S − {J}`.
- **Lemma.** Every tree in the `D_N`-component of `T` contains every self-certifying `S`.
- **Proof.** On a `D_N`-path from `T`, take the first tree that loses an element `J` of `S`. Its predecessor contains `S`, so the deleting rotation satisfies the laminarity conditions. It therefore has rank 3, and is not a `D_N`-flip. ∎
- **Greatest fixpoint.** The condition only gets weaker as `S` grows, so the union of all self-certifying sets is self-certifying. This union, `stable(T)`, is computed by deleting failing nodes until nothing changes.
- **Certificate.** A Moufang move `T → T′` with `stable(T) ⊄ nodes(T′)` joins two different `D_N`-components. It needs no component search.
- **Exact checks.** `stable(T)` lies inside the nodes common to the whole component for all 824,310 trees checked, n ≤ 8, with equality in 98 %.
- **Coverage.** The certificate exists for **every** non-interval 3-letter word with n ≤ 10 (12,624 words). It also exists for all six counterexamples to G3-R (n = 10, 12). See `stable_separators.py` and `data/stable10.log`. Example: `xyxyzzyxyx`, right comb `T₀`, `stable(T₀) = {[1,9], [2,9], [3,9], [4,9]}`. The move `x(y(xC)) → ((xy)x)C` deletes `[2,9]`. None of these four nodes is absolutely rigid; they certify each other.

**Q′ (run-comb family, P for all n).** Let `w` be a 3-letter word with runs `ρ₀ρ₁…`, starts `r₀ = 0 < r₁ < …` and letters `ℓ_t`. Fix `m ≥ 1` with:
- **(i)** for `1 ≤ t < m`, the letter outside `{ℓ_{t−1}, ℓ_t}` occurs in `w[r_{t+1}..]`;
- **(ii)** with `c = ℓ_{m−1}`, the two other letters never reach, on a nonempty proper prefix of `w[r_m..]`, the ratio they have on all of `w[r_m..]`.

Suppose some `1 ≤ t ≤ m` has `ℓ_{t−1} = ℓ_{t+1}` and `w[r_{t+1}+1..] ≠ ∅`. Then `w` has a disconnected class. The same holds for the reversed word.
*Proof.* Take `T₀` to be the right comb over letters, except that `Y = ρ_t` forms one block. We show that `S = {[r_u, n−1] : 1 ≤ u ≤ m}` is self-certifying (Lemma R′).
- *Rotations deleting `[r_u, n−1]`.* Laminarity with `S` forces the sibling to be a suffix `c′ᵏ` of the run `ρ_{u−1}`. It also forces the left child to lie inside the block from `r_u` to the next start in `S`.
- *Case `u < m`.* The left child is a nonempty piece of the single-letter run `ρ_u`, and the right child contains the third letter by (i). The determinant is ± (count of the third letter) ≠ 0.
- *Case `u = m`.* Every split `[r_m..s] | [s+1..n−1]` is allowed, and the determinant is exactly the ratio test (ii).

The move `x(Y(xC)) → ((xY)x)C` at the last letter of `ρ_{t−1}` is an instance of the left Moufang identity, and it deletes `[r_t, n−1] ∈ S`. ∎

`run_comb.py` re-checks every certificate against `stable(T₀)` and the explicit move, with no failures. Q′ alone covers 92.6 % of non-interval 3-letter words at n = 9. Combined with Theorem B, it leaves 1, 4, 4, 11, 6 words at n = 7, 9, 10, 11, 12, for example `xyyxzzx` and `xyxxyxzxxzx`. A *zipper* tree, which is a right comb on a prefix and a left comb on the suffix, certifies those (`stable_separators.py`).

**Cat (caterpillar certificates, P).** This applies to a 3-letter word `w` with runs `ρ₀ … ρ_{R−1}` and run letters `s = s₀ … s_{R−1}`.
- **Caterpillars.** A *caterpillar* is a sequence of steps that peel runs off the ends of the current interval of runs. Each step is one of:
  - **L** peels the left end run;
  - **R** peels the right end run;
  - **D** peels both end runs, allowed when they carry the same letter.

  The steps run down to a *bottom* of two runs. The path intervals are `J₀ = w ⊃ J₁ ⊃ … ⊃ J_K`, and `S = {J₁, …, J_K}`.
- **The tree `T₀`.** Peeled runs hang off the path letter by letter, except as the move below requires. Each `J_k` is a node of `T₀`.
- **Lemma.** `S` is self-certifying (Lemma R′) when:
  - **(C1)** for every `J_k`, `1 ≤ k < K`, entered by peeling letter `a` and left by peeling letter `b`: `a ≠ b`, and the third letter `c(a, b)` occurs in `J_{k+1}`;
  - **(C2)** the bottom `J_K`, with runs `u, v` and entry letter `a`, has `a, u, v` pairwise distinct.
- **Proof.** Let `J ∈ S`.
  - *Sibling.* Laminarity with the nearest `S`-ancestor `P` (or the root) forces the sibling `I` of a deleting rotation inside `P ∖ J`. So `I` is a piece of the run(s) peeled to reach `J`, all carrying letter `a`.
  - *Split.* Laminarity with the next `S`-node `J′` forces the split of `J` to cut inside a run peeled next (letter `b`), leaving `J′` whole on the other side. If `J` is the bottom, any split is allowed.
  - *Determinant.* In every case two of the three segments are single-letter pieces `aⁱ`, `bʲ`, so `det N = ± i·j·(count of c(a, b) in the third segment)`. The third segment contains `J′`. For the bottom, a direct 3 × 3 computation gives `± i·(…)·det(e_a, e_u, e_v)`.
  - *Laminarity of the new node.* The node created by each such rotation stays laminar with `S − {J}`, so every case is covered. ∎
- **Moves.** Each of the following Moufang moves deletes a node of `S`, so it joins two different `D_N`-components:
  - **M-mid.** A **D** step at `J_k = xᵐ·BC·x^{m′}` uses `x((BC)x) → (xB)(Cx)`, the middle Moufang identity. It deletes `BC = J_{k+1}`. `B, C` are the children of `BC`, both nonempty.
  - **M-left.** Two consecutive **L** steps peel runs `σ, Y`, and the next left run carries the letter of `σ`. If yet another step follows, it must also be **L**. Then `x(Y(xC)) → ((xY)x)C` is the left Moufang identity, with `Y` a block and `x` the letters adjacent to `Y`. It deletes `J_{k+1} = Y·…`.
  - **M-right.** The mirror image of M-left.

  `caterpillar.py` builds `T₀` for every non-interval 3-letter word with n ≤ 9. It confirms `S ⊆ stable(T₀)` and that a Moufang move deletes the predicted node: 4,330/4,330.

**Proposition E (existence, P for all R).**
- **Definitions.** A run sequence `s` is *valid* if it has three letters and `R ≥ 4` runs, i.e. it comes from a non-interval 3-letter word. Let `Good(s, e)` mean: `s` has a caterpillar satisfying (C1), (C2) and some move, where the root, *entered* by a letter `e`, also satisfies (C1). `e = ∅` means no entry.
- **Statement.** `Good(s, e)` holds unless one of the following holds:
  - **(F1)** `e = s₀ = s_{R−1}`;
  - **(F2)** `s₀ = e` and `s₀ … s_{R−2}` uses only two letters;
  - **(F2′)** the mirror image of (F2).

  In particular `Good(s, ∅)` always holds.
- **Proof.** Induction on `R`. The base `R ∈ {4, 5}` is a finite exhaustive check (`caterpillar.py`: 240 pairs). Let `R ≥ 6` and assume `(s, e)` is not a failure. Once the remainder after a peel is valid, it contains all three letters, so the third-letter part of (C1) holds automatically.
  - **Fact.** A valid `s` with `R ≥ 5` cannot become invalid on dropping either end run. If both `s₁…` and `…s_{R−2}` were invalid, both would be 2-letter alternating. Then `s₀` and `s_{R−1}` would each be a unique letter, which is impossible.
  - **Case `s₀ ≠ s_{R−1}`.** Peel **L** if `e ≠ s₀` and `s₁…` is valid. `Good(s₁…, s₀)` follows by induction, because:
    - (F1) and (F2) would need `s₁ = s₀`;
    - (F2′) would need `s_{R−1} = s₀`.

    Otherwise peel **R**, symmetrically. Both peels fail only when, say, `e = s₀` and `…s_{R−2}` is invalid. Then `…s_{R−2}` is 2-letter (it has ≥ 5 runs, hence a repeat), which is (F2).
  - **Case `s₀ = s_{R−1} = p`**, so `e ≠ p`. Let `s′ = s₁ … s_{R−2}` (≥ 4 runs).
    - If `s′` is valid, step **D**. `Good(s′, p)` holds by induction, since `p` is neither end letter of `s′`. The **D** step itself supplies the move.
    - Otherwise `s′` alternates two letters `a, b ≠ p`. Peel **L** and use `Good(s₁…, p)`. Neither (F1) nor (F2) applies, because `s₁ ≠ p`. (F2′) fails because `s₂…` contains `a`, `b` and `p`. ∎

  `caterpillar.py` also confirms the exact characterization for every pair `(s, e)` with `6 ≤ R ≤ 13`, as a sanity check.

The chain: `propC_iff` (a distinct-letter triple separates them), killing and renumbering to a three-block word, `Coeff.coef_moment` (the moment is the `sᵖ q tʳ` coefficient of the substituted polynomial), `Coeff.coef_of_map` (one Kronecker point determines all coefficients), `Profiles.key_of_K` (the linear moments give `N` and `M(0)`; Proposition S decodes the invariant), `PropT.propT`.

- **The loop closed (Lean).** `WExist.lemmaW_exists`: modulo `M⁴` the substitution `ℓ ↦ 1 + M q_ℓ` is the truncated series of `lemmaW_expansion`, so a rank-3 flip has `[A, B, C] ≡ 2·det·M³ e₇ ≢ 0` at `M = 2|det| + 1`; with context cancellation, every map-preserving flip is a `D_N`-flip, for every word (`kerflip_dn`). `MainThm.main`: kernel classes are flip-connected iff `≤ 2` letters or interval. The "if" half renumbers letters by runs and uses `Closure`; the "only if" half kills all but three letters `a, b, c` of a pattern `a…b…a`, takes the G3 caterpillar pair `g3_trees` of the three-letter word, carries it to octonion bracketings (Moufang moves and `D_N`-components transfer), and lifts it with `lift_separates`: two equal maps (Moufang) in different `D_N`-components, so in different flip-components of their kernel class. `Count.count_disconnected`: over restricted growth strings the number of words with a disconnected class is `Bell(n) − 2ⁿ + n`.
- **Prolog.** `assembly.pl` computes the substituted polynomial by octonion polynomial multiplication and checks the coefficient–moment identity, recovers `N` and `M` from the coefficients alone, and runs the G2 construction on every separated pair of small interval words.

**Theorem G3 (P for all n).** Every non-interval word over exactly three letters has a Moufang move between different `D_N`-components. Hence (K) every non-interval word with ≥ 3 letters has a disconnected kernel class.
*Proof.* Its run sequence is valid. Proposition E gives a caterpillar, Lemma Cat gives a self-certifying `S` and a Moufang move deleting a node of `S`, and Lemma R′ puts `T₁` in a different `D_N`-component. Lemma W turns this into disconnection, and Lemma K lifts it to words with more letters (restrict to `p, q` from a pattern `p…q…p` and any third letter). ∎

**Main theorem, all n.** "If": ≤ 2 letters (Artin) and Theorem G2. "Only if": Theorem G3. So the number of words of length `n` with a disconnected class is `Bell(n) − 2ⁿ + n` for every `n`. The local certificates for n ≤ 14 and the exact classification for n ≤ 9 agree with it.

**Distinct letters (P, general).** If all letters are distinct, all `C_{n−1}` bracketings are pairwise different maps (so `s_n(𝕆) = C_{n−1}`).
*Proof.* Distinct planar binary trees differ in the shape they induce on some leaf triple. Kill every other letter; the two induced bracketings of `xyz` differ, and `[x,y,z] ≢ 0`. ∎

## The theorem

- **≤ 2 letters (P).** One class, by Artin's theorem.
- **Finite cases (P-fin, n ≤ 9: 5 + 15 + 52 + 203 + 877 + 4140 + 21147 words).** `verify_theorem.py` decides every word exactly:
  - *Non-interval:* it finds an axiom move (an instance of a law valid in every alternative algebra, replayable as a ZFC-A- certificate) between two different `D_N`-components. Disconnected by W.
  - *Interval:* every `D_N`-edge satisfies V (Lemma I), and the `D_N`-components are pairwise separated by the `I_v` invariants (Θ) or, where those tie, by exact int64 evaluation at integer octonions. Distinct values prove distinct maps.
  - No randomized identity tests are used.
- **General n reduces to two combinatorial claims, both now proved: G2 (Theorem G2 below) and G3 (Theorem G3 below).**
  - **(G2, P)** In an interval word, distinct `D_N`-components are distinct maps (no non-local identities).
  - **(G3, P)** Every non-interval word over **exactly three** letters has a **Moufang** move between different `D_N`-components. By K this implies the disconnection claim for every non-interval word with ≥ 3 letters. `g3_check.py` verifies G3 exactly for all 4,330 such words of lengths 4 through 9 (3 + 19 + 80 + 286 + 945 + 2,997). Local certificates (Theorem B, Proposition Q′, Lemma R′) extend this to every such word of length ≤ 14 (see Progress below).
  - **(G3-R), the stronger, local form.** Every such word has a Moufang move toggling an absolutely rigid interval. `rigid_separators.py` verifies it for every word of length ≤ 9 (see `data/rigid9.log`). **It is false in general:** `xyxyzzyxyx`, `xyyxzzxyyx` (n = 10) and four words at n = 12 have no rigid separator. G3 itself still holds for all six (exact `D_N`-component check). Two-letter separators do **not** suffice: separators of length 2 through 6 occur already at n = 7. A general proof needs a uniform choice of (move, J). One family is already uniform: `J = a bᵐ a` over two letters is rigid iff no split balances the `a : b` ratio and both sides of `J` are the third letter or the boundary.
- **Count.** With the characterization, the non-local words are those with ≥ 3 letters that are not interval words: `Bell(n) − 2^{n−1} − (2^{n−1} − n) = Bell(n) − 2ⁿ + n`.

## Progress towards all n (2026-11-18)

**F (factor reduction, P).** Let `J` be absolutely rigid in `w`, and `u = w[J]`. Then restricting to the subtree at `J` maps `D_N(w)`-paths through bracketings containing `J` to `D_N(u)`-paths: flips inside `J` see the same count matrices, flips outside treat `J` as one block, and no flip removes `J`. So a Moufang pair separated in `u` lifts, inside any fixed context, to a separated Moufang pair in `w`. G3 for `w` follows from G3 for any rigid non-interval 3-letter proper factor.

**Theorem B (P, every n).** Let `w` be a 3-letter word. Suppose some letter `r` has a maximal `r`-free block `J` over `{p, q}` such that:
- **(R1)** `J` contains both `p` and `q`, and no proper prefix of `J` has the `p : q` ratio of `J`;
- one of the following holds:
  - **(M1)** the first letter of `J` occurs after `J`;
  - **(M2)** the last letter occurs before `J`;
  - **(M4)** the first letter occurs before `J`;
  - **(M5)** the last letter occurs after `J`;
  - **(M3)** `J` begins and ends with the same letter.

Then `w` has a disconnected kernel class.
*Proof.* (R1) together with the `r`/boundary flanks is exactly absolute rigidity of a two-letter interval (closed form above). Each condition names a Moufang move that toggles node `J`:
- M1: `(pB)(Cp) ↔ p((BC)p)` with `J = pB`;
- M2: `(sB)(Cs)` with `J = Cs`;
- M4: `((pB)p)C ↔ p(B(pC))` with `J = pC`;
- M5: `((Cs)B)s` with `J = Cs`;
- M3: `((pB)p)C` or `C((pB)p)`, with `J = (pB)p`.

The repeated variable is a single letter in every case, and every gap borders the third letter, so all variables are nonempty. Lemma R gives different `D_N`-components, and Lemma W gives disconnection. ∎

By Lemmas F and K the theorem extends to every word that has a rigid factor, or a 3-letter killing image, satisfying the hypotheses. Interval words never satisfy M1–M5 (they need a letter to recur around another), consistent with G2.

*Coverage* (`block_witness.py`, exhaustive): 100 % of non-interval 3-letter words for n ≤ 6 and n = 8; 99.55 % at n = 12 (86,079 / 86,471). Lemma R′ alone covers all words with n ≤ 10 (`data/stable10.log`). For 11 ≤ n ≤ 14, every word is covered by Theorem B, by Proposition Q′, or by a stable-node certificate from Lemma R′. At n = 13 these cover 260,015, 1,496 and 48 words; at n = 14, 786,168, 2,696 and 28 (`g3_upto14.py`, `data/g3_upto14.log`). **So G3, and with it the full theorem, holds for every n ≤ 14 by local certificates.** Every non-interval word with ≥ 3 letters has a non-interval 3-letter restriction of no greater length (keep `p, q` from a pattern `p…q…p` and any third letter), and Moufang moves lift (K). *(Superseded: Theorem G3 above gives the uniform rule, caterpillar certificates, and proves G3 for all n.)*

**G2 reduction (rigorous implication; both inputs discharged below).** Killing letters is a specialisation, so equal maps restrict to equal maps. Hence G2 follows from:
- **(a)** the components of the letter-triple restrictions determine the `D_N`-component, for interval words (verified for all interval words with ≥ 4 letters, n ≤ 7, `g2_reduction.py`);
- **(b)** G2 for three-block words `xᵃyᵇzᶜ`. This is verified for all 162 such words with `a + b + c ≤ 11`, and their component count fits

  `#components(xᵃyᵇzᶜ) = 1 + b·(C(a+c, a) − 1)`   (proved below, Proposition T).

**Proposition T (three-block components, P for all a, b, c).** Let `w = xᵃyᵇzᶜ`.
- **Core and invariant.** For a bracketing `T`, let the core `K = (U, V)` be the lowest node containing the last `x` and the first `z`. Then `U = x^{a′}y^j` and `V = y^{b−j}z^{c′}` with `a′, c′ ≥ 1`. Every ancestor of `K` attaches a pure-`x` block on the left or a pure-`z` block on the right. Let `W` be the word of attached letters read from `K` outward. Put `Φ(T) = (j, a′, c′, W)`.
- **Classification.** `j` is constant on `D_N`-components. For `0 < j < b`, `Φ` is a complete invariant. For `j = 0` (resp. `j = b`), the complete invariant is the join word from the core outward, where core `x`'s (resp. `z`'s) merge with the adjacent outer run.
- **Count.**

  `#D_N-components(xᵃyᵇzᶜ) = (b−1)(C(a+c,a) − 1) + C(a+c−1, a) + C(a+c−1, c) = 1 + b·(C(a+c,a) − 1).`

*Proof.* Flips inside `U`, inside `V` or inside a one-letter block involve at most two letters, so they keep `Φ`. The remaining flips are:
- rotation at `K` moving an `x`-block across: determinant `p·j·c′`;
- rotation at `K` moving `k` `y`'s across: determinant `a′·k·c′`;
- an `x`-attachment against a `z`-attachment, through a node holding `n_y ≥ 1` `y`'s: determinant `p·q·n_y`;
- merging two adjacent attachments on the same side: they are powers of one letter, so the flip is in `D_N` and leaves `W` unchanged.

So `j` never changes. For `0 < j < b`, `a′` and `c′` never change either. For `j = 0` (resp. `j = b`) the first determinant vanishes, and only the merge of core `x`'s (resp. `z`'s) with the adjacent outer run becomes possible.

*Completeness.* Trees with equal invariant differ only in bracketings of ≤ 2-letter regions and in the grouping of consecutive same-side blocks; these are joined by `D_N` moves.

*Counting.* For interior `j`: `Σ_{p<a, q<c} C(p+q, p) = C(a+c, a) − 1`. For `j = 0`: `Σ_{q<c} C(a−1+q, a−1) = C(a+c−1, a)`; symmetrically for `j = b`. Pascal's rule gives the total. ∎ (`three_block.py` checks invariant completeness and counts for `a ≤ 3, b ≤ 4, c ≤ 3`.)

Consequently, G2 for three-block words is equivalent to: different invariants `Φ` give different octonion maps. This is proved next.

**Lemma M (moment formula, P for all a, b, c).** Substitute `x = 1 + s e₁`, `y = 1 + q e₂`, `z = 1 + t e₄` into a bracketing `T` of `xᵃyᵇzᶜ`, and let `A_T(p, r)` be the coefficient of `sᵖ q tʳ`. Put
`ω₊ = x^{a′} z^{c′} W`, `ω₋ = z^{c′} x^{a′} W` (as words in `x, z`; `Φ(T) = (j, a′, c′, W)`). For a word `ω` in `x, z`, let `P_ω ∈ Cl₂[s, t]` be the ordered product of `1 + sX` per `x` and `1 + tZ` per `z`, with `X² = Z² = 1`, `XZ = −ZX`. Let `S_ω(p, r)` be its `sᵖtʳ` coefficient. Then

  `A_T(p, r) = σ(p, r) · [ j·S_{ω₊}(p, r) + (b − j)·S_{ω₋}(p, r) ]`,  with the sign `σ` independent of `T`.

*Proof.* `A_T(p, r)` sums, over `p` x-leaves, one y-leaf `y_k` and `r` z-leaves, the value of `T` restricted to them on the units `e₁, e₂, e₄`. Let `H = ⟨e₁, e₄⟩ ≅ ℍ` and `ℓ = e₂ ⊥ H`. Then `𝕆 = H ⊕ Hℓ` with `h(cℓ) = (ch)ℓ` and `(cℓ)h = (c h̄)ℓ`. Subtrees without `y_k` lie in the associative `H` and evaluate to ordered products. Walking from `y_k` to the root, the value stays `cℓ`: a left sibling `h` appends `h`, and a right sibling appends `h̄`.

Left siblings hold only letters left of `y_k` (x's, after deleting other y's). Right siblings hold only z's, and `conj(e₄ᵐ) = (−1)ᵐ e₄ᵐ`. So the value is `(−1)ʳ e^{ω_k} ℓ`, where `ω_k` is the word of absorbed blocks read bottom-up and `e^{ω}` its ordered unit product. Summing over the subsets gives the `sᵖtʳ` coefficient of the ordered product in `H`. Reducing to `e₁^{[p]}e₄^{[r]}` uses the same inversion sign as `Cl₂` and a square sign depending only on `(p, r)`.

By Proposition T, the ancestors of `y_k` absorb the attachments in order `W`. Below them, they absorb the core: if `y_k` is in the core's left child (`j` choices), all core x's and then the core z's (`ω_k = ω₊`); otherwise the core z's and then the core x's (`ω_k = ω₋`). ∎ (`lemma_m.py`: exact agreement on every bracketing, n ≤ 7, and on every component, n = 8.)

**Proposition S (separation, P for all a, b, c).** Distinct `D_N`-components of `xᵃyᵇzᶜ` have distinct octonion maps. Already the moments `A(p, 1)` and `A(1, r)` separate them.

*Proof.* In the `t`-linear part of `P_ω`, each `z` with `α` x's before it contributes `A^α Z A^{a−α} = Z Ā^α A^{a−α}`, where `A = 1+sX` and `Ā = 1−sX`. On the `X = +1` eigenline these are `(1−s)^α(1+s)^{a−α}`, `α = 0..a`, a basis of polynomials of degree ≤ a. So the `t`-linear moments determine the weighted z-profile `N(α) = j N_{ω₊}(α) + (b−j) N_{ω₋}(α)`, where `N_ω(α)` counts the z's of `ω` preceded by exactly `α` x's. Symmetrically, the `s`-linear moments determine the x-profile `M(γ)`. Explicitly,

  `N = b·N_W(· − a′) + j c′ δ_{a′} + (b−j) c′ δ₀`,  `M = b·M_W(· − c′) + j a′ δ₀ + (b−j) a′ δ_{c′}`.

- If `N(0), M(0) > 0`, then `j` is interior. In that case `a′ = min{α > 0 : N(α) ≠ 0}`, `c′ = min{γ > 0 : M(γ) ≠ 0}` and `j = b − N(0)/c′`. Then `N_W` follows by subtraction. A binary word is fixed by its z-profile and its number of x's, so `W` is determined.
- If `M(0) = 0`, then `j = 0` and `N = b·N_{ω₋}`. If `N(0) = 0`, then `j = b` and `N = b·N_{ω₊}`. Either way the profile fixes the join word, which is the complete invariant for boundary `j` (Proposition T). ∎ (`lemma_m.py` decodes every component, n ≤ 8, and checks injectivity of the formula over all `Φ` with `a + b + c ≤ 12`: 15,133 maps, count `1 + b(C(a+c,a) − 1)` each.)

**Corollary (G2 for three-block words, P for all a, b, c).** For `xᵃyᵇzᶜ`, kernel classes coincide with `D_N`-components and are flip-connected. Input (b) of the G2 reduction is therefore proved.

**Proposition C (D_N-components of interval words, P for all n).** Let `w` be an interval word. For a bracketing `T`, let `σ(T)` record the shape, `((ij)k)` or `(i(jk))`, that `T` induces on each leaf triple `i < j < k` whose letters `wᵢ, wⱼ, w_k` are pairwise distinct. Then `T, T′` lie in the same `D_N`-component iff `σ(T) = σ(T′)`.

*Proof.*
- **(⇒)** A flip `(AB)C → A(BC)` changes exactly the shapes of the triples in `A × B × C`. If it is a `D_N`-flip, Lemma I says `abc` has ≤ 2 letters or two of `a, b, c` are powers of one letter. In an interval word, `a` and `c` powers of `x` force `b` to be a power of `x` too. In every case each triple of `A × B × C` repeats a letter, so `σ` is unchanged.
- **(⇐)** Induction on `n`; words with ≤ 2 letters have a single component. Let `T = (T_L, T_R)` and `T′ = (T′_L, T′_R)` have root splits after positions `m` and `m′`.
  - *Equal splits.* If `m = m′`, `σ` restricts to the two factors, and `D_N`-flips inside a subtree are `D_N`-flips of `T` (the count matrix is local). Induction applies to each side.
  - *Unequal splits.* Say `m < m′`. Every triple `(i, j, k) ∈ [1,m] × (m,m′] × (m′,n]` has shape `i(jk)` in `T` and `(ij)k` in `T′`. So no such triple has three distinct letters. Let `X, Y, Z` be the letter sets of the three segments; then every `x ∈ X, y ∈ Y, z ∈ Z` has `x = y` or `y = z`, with letters ordered by block (`x ≤ y ≤ z`). If `|Y| ≥ 3`, a middle letter of `Y` gives a distinct triple. If `Y = {y₁ < y₂}`, then `X = {y₁}` and `Z = {y₂}`, so `w` has two letters. If `Y = {y}`, then `X = {y}` or `Z = {y}`.
  - *Case `X = Y = {y}`* (`w[1..m′]` is a power of `y`). Let `T″ = (P, T′_R)` on `w[m+1..n]`, with `P` any bracketing of `(m, m′]`. Its distinct-letter triples lie in `(m′, n]`, where `T″` agrees with `T′`, or have the shape `i(jk)` with `i ∈ (m, m′]`. `T` has the same shape there because `σ(T) = σ(T′)`. So `σ(T_R) = σ(T″)`, and by induction `T_R ∼_D T″`. Then `(T_L, (P, T′_R)) → ((T_L, P), T′_R)` is a `D_N`-flip, since `a, b` are powers of `y`. Its root split is `m′`, which reduces to the case of equal splits.
  - *Case `Y = Z = {y}`* is the mirror image, applied to `T′`. ∎

`sigma_complete.py` confirms it on all 72,622 components of the 247 interval words with n = 9 (and all n ≤ 9).

**Theorem G2 (P for all n).** In an interval word, distinct `D_N`-components are distinct maps. Hence the kernel classes are exactly the `D_N`-components, and they are flip-connected.
*Proof.* Take `T, T′` in different components. By Proposition C, they induce different shapes on a leaf triple with distinct letters `p < q < r`. Kill every other letter; both restrictions are bracketings of the three-block word `pᵃqᵇrᶜ` and still differ on that triple. By Proposition C (⇒) they lie in different components, and by Proposition S they are different maps. Killing is a specialisation, so `T ≁ T′`. Lemma I makes each component lie inside one class. ∎

This also proves input (a), triple-restriction completeness, as a corollary. **The "if" direction of the theorem — interval words and ≤ 2-letter words have only flip-connected classes — is proved for all n.**
