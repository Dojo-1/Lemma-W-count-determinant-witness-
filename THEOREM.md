# Flip-connectivity of octonion bracketing classes

Evidence labels: **P** proved (general argument), **P-fin** proved for every word of the stated lengths by an exact, sampling-free computation built only from the lemmas below, **H** open.

## Setting

A *word* `w = w₁…wₙ` over letters; a *bracketing* is a planar binary tree with leaves `1..n`. Each bracketing `T` induces a polynomial map `𝕆^L → 𝕆`. `T ~ T'` iff the maps agree. Bracketings form the vertices of the associahedron `Kₙ`; an edge (*flip*) replaces a subterm `(AB)C` by `A(BC)`, where `A, B, C` are bracketings of consecutive segments `a, b, c` of `w`. A class is *flip-connected* if it induces a connected subgraph of `Kₙ`.

**Theorem (conjectured for all n; P-fin for n ≤ 9).** In 𝕆 every class of `w` is flip-connected iff `w` has ≤ 2 distinct letters or every letter of `w` occurs in one contiguous run. The number of words of length `n` (up to renaming) with a disconnected class is `Bell(n) − 2ⁿ + n`.

## General lemmas (P)

**L1 (context cancellation).** `C[S₁] ~ C[S₂] ⇔ S₁ ~ S₂` for any context `C`.
*Proof.* `C[S]` is `S` composed with left/right multiplications by values of the other subterms of `C`. For generic letter values these are nonzero, and multiplication by a nonzero octonion is bijective (𝕆 is a division algebra). So equality on a dense set forces `S₁ = S₂` on a dense set, hence identically. ∎
*Consequence.* A flip is an edge inside a class iff its local associator `[A,B,C]` vanishes identically.

**W (count-determinant witness).** Let `N` be the 3 × |letters| matrix of letter multiplicities of `a, b, c`. If `rank N = 3` then `[A,B,C] ≢ 0` for all bracketings `A, B, C`.
*Proof.* Pick letters `x, y, z` with `det N_{xyz} ≠ 0`. Specialise `x, y, z ↦ exp(θe₁), exp(θe₂), exp(θe₄)` and all other letters `↦ 1`. Each segment equals `1 + θΣₛ + O(θ²)` with `Σₛ = Σ N_{s,ℓ} e_ℓ`. The associator vanishes when an argument is real, so `[A,B,C] = θ³[Σ_a, Σ_b, Σ_c] + O(θ⁴)`. By trilinearity and alternation this is `θ³ det(N_{xyz}) [e₁,e₂,e₄] + O(θ⁴)`, and `[e₁,e₂,e₄] ≠ 0` because `1, 2, 4` are independent in 𝔽₂³ (`e₄` lies outside the quaternion algebra spanned by `e₁, e₂`). ∎
*Corollary.* The in-class flip graph is a subgraph of `D_N` := {flips with `rank N ≤ 2`}. So **two equivalent bracketings in different `D_N`-components prove that their class is disconnected.**

**V (vanishing).** `[A,B,C] ≡ 0` if `abc` uses ≤ 2 letters, or two of `a, b, c` are powers of one letter `x`.
*Proof.* In the first case the values lie in an algebra generated by two letters; in the second, two values lie in `span{1, x}` (𝕆 is quadratic), and all three lie in the algebra generated by `x` and the third value. Artin's theorem makes either algebra associative. ∎

**I (interval rank lemma).** If `w` is an interval word, `a, b, c` are consecutive segments, `abc` has ≥ 3 letters, and no two of `a, b, c` are powers of one letter, then `rank N = 3`.
*Proof.* Order letters by block. Supports are letter-intervals with `max S_a ≤ min S_b`, `max S_b ≤ min S_c`.
- *Case |S_b| = 1*, `S_b = {p}`. Neither `a` nor `c` is a power of `p`, so `a` has a letter `x < p` and `c` has a letter `z > p`. On columns `(x, p, z)` the matrix is `[[aₓ, a_p, 0], [0, b_p, 0], [0, c_p, c_z]]`, with determinant `aₓ b_p c_z ≠ 0`.
- *Case |S_b| ≥ 2*, `p = min S_b < q = max S_b`; then `S_a ∩ S_c = ∅`. Either `S_a = {p}` or `a` has `x < p`; either `S_c = {q}` or `c` has `z > q`. Choose `y ∈ S_b` with `p < y < q` when it exists. In each of the four combinations the matrix on columns chosen from `{x or p} × {y or p or q} × {z or q}` is triangular with nonzero diagonal. If `S_a = {p}` and `S_c = {q}`, the ≥ 3-letter hypothesis forces such a `y` to exist. ∎
Exhaustive brute-force check: 1,997,801 segment triples of interval words up to length 12, 0 violations.
*Corollary.* For interval words the in-class flip graph **equals** `D_N` (W gives ⊆; I + V give ⊇). Classes are unions of `D_N`-components.

**Θ (θ³ invariant).** For integer vectors `v_ℓ ∈ ℤ³` let `I_v(T) = Σ_{i<j<k} det(v_{wᵢ}, v_{wⱼ}, v_{wₖ}) · s_T(i,j,k)`, with `s_T = +1` if `T` induces `((ij)k)` on `{i,j,k}` and `−1` if `(i(jk))`. If `I_v(T) ≠ I_v(T')` then `T ≁ T'`.
*Proof.* Specialise `ℓ ↦ exp(θ q_ℓ)` with `q_ℓ = v_ℓ¹e₁ + v_ℓ²e₂ + v_ℓ³e₄`. Up to `θ³`, two bracketings differ only through associators of three distinct positions. Repeated-letter triples cancel (flexible and alternative laws). Associators of three generic elements of the span of `e₁, e₂, e₄` equal `det · [e₁,e₂,e₄]`. So `value(T) − value(T') = ½(I_v(T) − I_v(T'))[e₁,e₂,e₄]θ³ + O(θ⁴)`. ∎

**K (killing).** Setting a letter to `1` sends bracketings of `w` to bracketings of the shorter word `w′`. It maps `D_N`-edges to `D_N`-edges or to identities (deleting columns cannot raise rank), and identities to identities. **Moufang moves lift.** In each pattern, `(ab)(ca)`, `((ab)a)c`, `((ca)b)a`, every gap between consecutive leaves borders a non-repeated variable (`b` or `c`), so killed letters can be absorbed there or into the context. Hence a Moufang move between different `D_N`-components of `w′` lifts to one in `w`. (Alternative-law moves need not lift: `(xx)y` from `x d x y`.)

**R (rigid separator).** Call an interval `J` (|J| ≥ 2) *absolutely rigid* if every triple (split of `J`, adjacent nonempty interval on either side) has `rank N = 3`.
- **Lemma.** If `J` is absolutely rigid, then "`J` is a node of `T`" is constant on `D_N`-components.
- **Proof.** A node with span `J` is created or removed only by a rotation at its parent in which `J` is the inner node. That rotation's segment triple is (split of `J`, sibling), and the sibling is an adjacent nonempty interval. By rigidity it has rank 3, so it is not a `D_N`-edge. ∎
- **Closed form (three letters).** Let `t = counts(J)`, and `n_s = u_s × t` for each split `s` (`u_s` = counts of the left part). `J` is rigid iff no nonempty prefix-count vector of the right context and no nonempty suffix-count vector of the left context is orthogonal to any `n_s`, i.e. two lattice walks avoid finitely many planes. For `J = pq`: rigid iff each side of `J` is the word boundary or the third letter.
- **Consequence.** A Moufang move `T0 → T1` together with a rigid `J ∈ nodes(T0) Δ nodes(T1)` is a *local, finitely checkable* certificate that `T0, T1` lie in different `D_N`-components: no component search is needed.

**Distinct letters (P, general).** If all letters are distinct, all `C_{n−1}` bracketings are pairwise different maps (so `s_n(𝕆) = C_{n−1}`).
*Proof.* Distinct planar binary trees differ in the shape they induce on some leaf triple. Kill every other letter; the two induced bracketings of `xyz` differ, and `[x,y,z] ≢ 0`. ∎

## The theorem

- **≤ 2 letters (P).** One class, by Artin's theorem.
- **Finite cases (P-fin, n ≤ 9: 5 + 15 + 52 + 203 + 877 + 4140 + 21147 words).** `verify_theorem.py` decides every word exactly:
  - *Non-interval:* it finds an axiom move (an instance of a law valid in every alternative algebra, replayable as a ZFC-A- certificate) between two different `D_N`-components. Disconnected by W.
  - *Interval:* every `D_N`-edge satisfies V (Lemma I), and the `D_N`-components are pairwise separated by the `I_v` invariants (Θ) or, where those tie, by exact int64 evaluation at integer octonions. Distinct values prove distinct maps.
  - No randomized identity tests are used.
- **General n reduces to two combinatorial claims (H):**
  - **(G2)** In an interval word, distinct `D_N`-components are distinct maps (no non-local identities).
  - **(G3)** Every non-interval word over **exactly three** letters has a **Moufang** move between different `D_N`-components. By K this implies the disconnection claim for every non-interval word with ≥ 3 letters. `g3_check.py` verifies G3 exactly for all 3,385 such words of length ≤ 9.
  - **(G3-R), the stronger, local form.** Every such word has a Moufang move toggling an absolutely rigid interval. `rigid_separators.py` verifies it for every word of length ≤ 9 (see `data/rigid9.log`). **It is false in general:** `xyxyzzyxyx`, `xyyxzzxyyx` (n = 10) and four words at n = 12 have no rigid separator. G3 itself still holds for all six (exact `D_N`-component check). Two-letter separators do **not** suffice: separators of length 2 through 6 occur already at n = 7. A general proof needs a uniform choice of (move, J). One family is already uniform: `J = a bᵐ a` over two letters is rigid iff no split balances the `a : b` ratio and both sides of `J` are the third letter or the boundary.
- **Count.** With the characterization, the non-local words are those with ≥ 3 letters that are not interval words: `Bell(n) − 2^{n−1} − (2^{n−1} − n) = Bell(n) − 2ⁿ + n`.

## Progress towards all n (2026-11-18)

**F (factor reduction, P).** Let `J` be absolutely rigid in `w`, and `u = w[J]`. Then restricting to the subtree at `J` maps `D_N(w)`-paths through bracketings containing `J` to `D_N(u)`-paths: flips inside `J` see the same count matrices, flips outside treat `J` as one block, and no flip removes `J`. So a Moufang pair separated in `u` lifts, inside any fixed context, to a separated Moufang pair in `w`. G3 for `w` follows from G3 for any rigid non-interval 3-letter proper factor.

**Theorem B (P, every n).** Let `w` be a 3-letter word. Suppose some letter `r` has a maximal `r`-free block `J` over `{p, q}` such that:
- **(R1)** `J` contains both `p` and `q`, and no proper prefix of `J` has the `p : q` ratio of `J`;
- one of the following holds:
  - **(M1)** the first letter of `J` occurs after `J`;
  - **(M2)** the last letter occurs before `J`;
  - **(M4)** the first letter occurs before `J`;
  - **(M5)** the last letter occurs after `J`;
  - **(M3)** `J` begins and ends with the same letter.

Then `w` has a disconnected kernel class.
*Proof.* (R1) together with the `r`/boundary flanks is exactly absolute rigidity of a two-letter interval (closed form above). Each condition names a Moufang move that toggles node `J`:
- M1: `(pB)(Cp) ↔ p((BC)p)` with `J = pB`;
- M2: `(sB)(Cs)` with `J = Cs`;
- M4: `((pB)p)C ↔ p(B(pC))` with `J = pC`;
- M5: `((Cs)B)s` with `J = Cs`;
- M3: `((pB)p)C` or `C((pB)p)`, with `J = (pB)p`.

The repeated variable is a single letter in every case, and every gap borders the third letter, so all variables are nonempty. Lemma R gives different `D_N`-components, and Lemma W gives disconnection. ∎

By Lemmas F and K the theorem extends to every word that has a rigid factor, or a 3-letter killing image, satisfying the hypotheses. Interval words never satisfy M1–M5 (they need a letter to recur around another), consistent with G2.

*Coverage* (`block_witness.py`, exhaustive): 100 % of non-interval 3-letter words for n ≤ 6 and n = 8; 99.55 % at n = 12 (86,079 / 86,471). Adding M6 and factor reduction leaves 2 words at n = 10 and 4 at n = 12, all near-palindromic balanced words. G3 holds for those by exact `D_N` search but not via a rigid node. **G3 for all n stays open:** what is missing is a separator mechanism for balanced near-palindromic words.

**G2 reduction (rigorous implication, two open inputs).** Killing letters is a specialisation, so equal maps restrict to equal maps. Hence G2 follows from:
- **(a)** the components of the letter-triple restrictions determine the `D_N`-component, for interval words (verified for all interval words with ≥ 4 letters, n ≤ 7, `g2_reduction.py`);
- **(b)** G2 for three-block words `xᵃyᵇzᶜ`. This is verified for all 162 such words with `a + b + c ≤ 11`, and their component count fits

  `#components(xᵃyᵇzᶜ) = 1 + b·(C(a+c, a) − 1)`   (proved below, Proposition T).

**Proposition T (three-block components, P for all a, b, c).** Let `w = xᵃyᵇzᶜ`.
- **Core and invariant.** For a bracketing `T`, let the core `K = (U, V)` be the lowest node containing the last `x` and the first `z`. Then `U = x^{a′}y^j` and `V = y^{b−j}z^{c′}` with `a′, c′ ≥ 1`. Every ancestor of `K` attaches a pure-`x` block on the left or a pure-`z` block on the right. Let `W` be the word of attached letters read from `K` outward. Put `Φ(T) = (j, a′, c′, W)`.
- **Classification.** `j` is constant on `D_N`-components. For `0 < j < b`, `Φ` is a complete invariant. For `j = 0` (resp. `j = b`), the complete invariant is the join word from the core outward, where core `x`'s (resp. `z`'s) merge with the adjacent outer run.
- **Count.**

  `#D_N-components(xᵃyᵇzᶜ) = (b−1)(C(a+c,a) − 1) + C(a+c−1, a) + C(a+c−1, c) = 1 + b·(C(a+c,a) − 1).`

*Proof.* Flips inside `U`, inside `V` or inside a one-letter block involve at most two letters, so they keep `Φ`. The remaining flips are:
- rotation at `K` moving an `x`-block across: determinant `p·j·c′`;
- rotation at `K` moving `k` `y`'s across: determinant `a′·k·c′`;
- an `x`-attachment against a `z`-attachment, through a node holding `n_y ≥ 1` `y`'s: determinant `p·q·n_y`;
- merging two adjacent attachments on the same side: they are powers of one letter, so the flip is in `D_N` and leaves `W` unchanged.

So `j` never changes. For `0 < j < b`, `a′` and `c′` never change either. For `j = 0` (resp. `j = b`) the first determinant vanishes, and only the merge of core `x`'s (resp. `z`'s) with the adjacent outer run becomes possible.

*Completeness.* Trees with equal invariant differ only in bracketings of ≤ 2-letter regions and in the grouping of consecutive same-side blocks; these are joined by `D_N` moves.

*Counting.* For interior `j`: `Σ_{p<a, q<c} C(p+q, p) = C(a+c, a) − 1`. For `j = 0`: `Σ_{q<c} C(a−1+q, a−1) = C(a+c−1, a)`; symmetrically for `j = b`. Pascal's rule gives the total. ∎ (`three_block.py` checks invariant completeness and counts for `a ≤ 3, b ≤ 4, c ≤ 3`.)

Consequently, G2 for three-block words is equivalent to: different invariants `Φ` give different octonion maps. This is proved next.

**Lemma M (moment formula, P for all a, b, c).** Substitute `x = 1 + s e₁`, `y = 1 + q e₂`, `z = 1 + t e₄` into a bracketing `T` of `xᵃyᵇzᶜ`, and let `A_T(p, r)` be the coefficient of `sᵖ q tʳ`. Put
`ω₊ = x^{a′} z^{c′} W`, `ω₋ = z^{c′} x^{a′} W` (as words in `x, z`; `Φ(T) = (j, a′, c′, W)`). For a word `ω` in `x, z`, let `P_ω ∈ Cl₂[s, t]` be the ordered product of `1 + sX` per `x` and `1 + tZ` per `z`, with `X² = Z² = 1`, `XZ = −ZX`. Let `S_ω(p, r)` be its `sᵖtʳ` coefficient. Then

  `A_T(p, r) = σ(p, r) · [ j·S_{ω₊}(p, r) + (b − j)·S_{ω₋}(p, r) ]`,  with the sign `σ` independent of `T`.

*Proof.* `A_T(p, r)` sums, over `p` x-leaves, one y-leaf `y_k` and `r` z-leaves, the value of `T` restricted to them on the units `e₁, e₂, e₄`. Let `H = ⟨e₁, e₄⟩ ≅ ℍ` and `ℓ = e₂ ⊥ H`. Then `𝕆 = H ⊕ Hℓ` with `h(cℓ) = (ch)ℓ` and `(cℓ)h = (c h̄)ℓ`. Subtrees without `y_k` lie in the associative `H` and evaluate to ordered products. Walking from `y_k` to the root, the value stays `cℓ`: a left sibling `h` appends `h`, and a right sibling appends `h̄`.

Left siblings hold only letters left of `y_k` (x's, after deleting other y's). Right siblings hold only z's, and `conj(e₄ᵐ) = (−1)ᵐ e₄ᵐ`. So the value is `(−1)ʳ e^{ω_k} ℓ`, where `ω_k` is the word of absorbed blocks read bottom-up and `e^{ω}` its ordered unit product. Summing over the subsets gives the `sᵖtʳ` coefficient of the ordered product in `H`. Reducing to `e₁^{[p]}e₄^{[r]}` uses the same inversion sign as `Cl₂` and a square sign depending only on `(p, r)`.

By Proposition T, the ancestors of `y_k` absorb the attachments in order `W`. Below them, they absorb the core: if `y_k` is in the core's left child (`j` choices), all core x's and then the core z's (`ω_k = ω₊`); otherwise the core z's and then the core x's (`ω_k = ω₋`). ∎ (`lemma_m.py`: exact agreement on every bracketing, n ≤ 7, and on every component, n = 8.)

**Proposition S (separation, P for all a, b, c).** Distinct `D_N`-components of `xᵃyᵇzᶜ` have distinct octonion maps. Already the moments `A(p, 1)` and `A(1, r)` separate them.

*Proof.* In the `t`-linear part of `P_ω`, each `z` with `α` x's before it contributes `A^α Z A^{a−α} = Z Ā^α A^{a−α}`, where `A = 1+sX` and `Ā = 1−sX`. On the `X = +1` eigenline these are `(1−s)^α(1+s)^{a−α}`, `α = 0..a`, a basis of polynomials of degree ≤ a. So the `t`-linear moments determine the weighted z-profile `N(α) = j N_{ω₊}(α) + (b−j) N_{ω₋}(α)`, where `N_ω(α)` counts the z's of `ω` preceded by exactly `α` x's. Symmetrically, the `s`-linear moments determine the x-profile `M(γ)`. Explicitly,

  `N = b·N_W(· − a′) + j c′ δ_{a′} + (b−j) c′ δ₀`,  `M = b·M_W(· − c′) + j a′ δ₀ + (b−j) a′ δ_{c′}`.

- If `N(0), M(0) > 0`, then `j` is interior. In that case `a′ = min{α > 0 : N(α) ≠ 0}`, `c′ = min{γ > 0 : M(γ) ≠ 0}` and `j = b − N(0)/c′`. Then `N_W` follows by subtraction. A binary word is fixed by its z-profile and its number of x's, so `W` is determined.
- If `M(0) = 0`, then `j = 0` and `N = b·N_{ω₋}`. If `N(0) = 0`, then `j = b` and `N = b·N_{ω₊}`. Either way the profile fixes the join word, which is the complete invariant for boundary `j` (Proposition T). ∎ (`lemma_m.py` decodes every component, n ≤ 8, and checks injectivity of the formula over all `Φ` with `a + b + c ≤ 12`: 15,133 maps, count `1 + b(C(a+c,a) − 1)` each.)

**Corollary (G2 for three-block words, P for all a, b, c).** For `xᵃyᵇzᶜ`, kernel classes coincide with `D_N`-components and are flip-connected. Input (b) of the G2 reduction is therefore proved; **G2 now rests only on (a)**, the triple-restriction completeness for interval words.
